# NIGHT STREETS (Rust)

Подпольные уличные гонки: 8 реальных машин, 3 трассы со срезками, гражданский трафик,
гараж с тюнингом (цвет, диски, подсветка, спойлер, апгрейды), деньги и сохранение.
Это порт Python-версии на Rust + [macroquad](https://macroquad.rs).

## Запуск

1. Установите Rust: https://rustup.rs (на Windows понадобятся "Build Tools for Visual Studio"
   с компонентом "Разработка классических приложений на C++" - установщик rustup подскажет).
2. В папке проекта:

```
cargo run --release
```

Первая сборка скачает macroquad и займёт несколько минут, дальше быстро.
Режим `--release` важен: без него игра будет тормозить.

## Управление

| клавиша | действие |
|---|---|
| W / ↑ | газ |
| S / ↓ | тормоз, задний ход |
| A D / ← → | руль |
| Пробел | ручник (дрифт) |
| Shift | нитро (заряжается дрифтом) |
| R | вернуть машину на трассу |
| Enter | старт гонки (в гараже) / в гараж (после финиша) |
| Esc | выход |

В гараже всё делается мышью: вкладки CAR / PAINT / TUNE и кнопка START RACE.
Срезки отмечены жёлто-чёрными столбами.

## Структура

| файл | что внутри |
|---|---|
| `src/carmodels.rs` | модели машин по реальным размерам и профилю кузова, колёса, трафик |
| `src/track.rs` | трассы, сплайн, срезки, "какая дорога под машиной" |
| `src/world.rs` | дорога, отбойники, арка, фонари, город |
| `src/car.rs` | физика, дрифт, нитро, ИИ, трафик, столкновения |
| `src/game.rs` | состояния, гонка, камера, отрисовка, HUD, гараж |
| `src/light.rs` | освещение: запекание и динамический свет машин |
| `src/mesh.rs` | склейка полигонов в куски для macroquad |
| `src/save.rs` | сохранение в `night_save.txt` |

Логика (всё кроме `game.rs`/`main.rs`) не зависит от движка.

## Графика

В macroquad нет освещения, отражений и теней, поэтому всё это считается вручную
(формулы в `src/light.rs`, проверены на Python-прототипе в `gfx_proto/`):

* **Машины.** Плавный кузов (кубическая интерполяция профиля, скруглённые плечи, закруглённые
  нос и корма), нормаль в каждой вершине. Свет считается на CPU каждый кадр: луна, ближайшие
  фонари, блики на лаке, отражение ночного неба в стёклах и дисках (эффект Френеля).
* **Дорога и мир.** Свет фонарей запечён в вершины асфальта, отбойников и зданий
  (светлые пятна под фонарями). Асфальт слегка прозрачный: сквозь него видна перевёрнутая
  копия машин (мокрая дорога), плюс размытые отражения фонарей.
* **Эффекты.** Ореолы вокруг фонарей, фар и стоп-сигналов, лучи фар, тени под машинами,
  подсветка днища, огонь нитро, дым дрифта.

Если картинка слишком тёмная или светлая, константы лежат в начале `src/light.rs`
(`SKY_AMB`, `MOON_COL`, `LAMP_I`, `LAMP_R`); прозрачность асфальта - `ROAD_ALPHA` в `src/world.rs`.

## Сохранение

Файл `night_save.txt` рядом с запуском. Сохранения из Python-версии (`night_save.json`)
не подхватываются.
